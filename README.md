# 🚀 C++ Mastery by Addhyan Tiwari

Welcome to **C.Plus-Plus**, an ultimate repository designed for beginners, intermediate learners, and advanced programmers who want to master C++ from scratch to a pro level. Whether you are exploring basic syntax or diving deep into Object-Oriented Programming (OOP) and algorithms, this repository is your **one-stop solution**. 🚀

This repository will contain **a vast collection of programs**, ranging from simple beginner-friendly examples to complex advanced projects. ## 📌 Getting Started

To use the programs in this repository, follow these steps:

1. **Clone this repository:**
   ```sh
   git clone https://github.com/addhyan94/C.Plus-Plus.git
   ```
2. **Navigate to the directory:**
   ```sh
   cd C.Plus-Plus
   ```
3. **Compile and run a program:**
   ```sh
   g++ program.cpp -o program
   ./program
   ```

## 📚 Learning Roadmap

If you're new to C++, follow this roadmap:

1️⃣ **Basics of C++** (Syntax, Variables, Data Types, Loops, Functions)  
2️⃣ **Intermediate Concepts** (Pointers, Memory Management, File Handling)  
3️⃣ **Object-Oriented Programming (OOP)** (Classes, Objects, Inheritance, Polymorphism)  
4️⃣ **Advanced Topics** (STL, Templates, Multi-threading, Networking in C++)  
5️⃣ **Projects & Problem-Solving** (Mini-projects and competitive programming)
