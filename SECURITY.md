# 🔒 Security Policy

## 📌 Supported Versions
We actively support the latest version of this repository. If you find any security vulnerabilities, please report them immediately.

| Version  | Supported |
|----------|-----------|
| Latest   | ✅ Active Support |
| Older    | ❌ No Support |

## ⚠️ Reporting Security Issues
If you discover a security issue in this repository, please follow these steps to ensure a safe resolution:

1. **📩 Report Privately:** Do **NOT** disclose security issues publicly.
2. **📧 Contact Us:** Send an email to **addhyant85@gmail.com** with:
   - A **detailed description** of the issue.
   - Steps to reproduce the vulnerability.
   - Any potential impact or risks associated.
3. **🛠️ Investigation & Fix:** We will review your report and work on resolving the issue as soon as possible.
4. **🔐 Responsible Disclosure:** Once the fix is deployed, we may publicly acknowledge your contribution (if you agree).

## 🔑 Security Best Practices
To ensure a safe and secure experience:
- **Avoid sharing sensitive information** in discussions or commits.
- **Use safe coding practices** to prevent vulnerabilities like buffer overflows, memory leaks, and undefined behaviors.
- **Keep dependencies updated** to avoid security risks.
- **Validate user inputs** to prevent potential exploits.

We appreciate your efforts in making this project **secure and reliable!** 🛡️✨
